# AWS modules

Planned, to match the Azure set and share the output contract
(see [docs/MODULE_STANDARD.md](../../docs/MODULE_STANDARD.md)):

- `vpc` — analogue of `azure/vnet`
- `aurora-postgres` — analogue of `azure/postgres-flexible`
- `elasticache-redis` — analogue of `azure/redis-premium`
- `s3` — analogue of `azure/blob`
- `secrets-manager` — analogue of `azure/keyvault`
- `ecr` — analogue of `azure/acr`
- `eks` — analogue of `azure/aks`
- `runner-asg` — analogue of `azure/runner-vmss`
- `irsa` — analogue of `azure/workload-identity`
