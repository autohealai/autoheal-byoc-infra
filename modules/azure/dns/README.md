# Autoheal BYOC - DNS records

A records for the Autoheal hostnames in a DNS zone the customer already has,
public or private. The module never creates the zone. Record names are relative
to the zone, with `@` for the apex. The AWS analogue is the Route 53 records
module. Naming and tags follow the repo's null-label convention (see `label.tf`
and [docs/MODULE_STANDARD.md](../../../docs/MODULE_STANDARD.md)).

## Usage

See [examples/basic](examples/basic) for a runnable configuration.
